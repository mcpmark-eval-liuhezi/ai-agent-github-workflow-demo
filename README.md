# ai-agent-github-workflow-demo
Demo repository for a hands-on walkthrough of an AI agent running a full GitHub development workflow end-to-end (branch, commit, PR, Copilot code review).

## Purpose

This repository is a live exhibit for our research group's demo on AI-driven development workflows. It demonstrates that an AI agent can, with only the standard GitHub APIs:

1. Create a branch with a meaningful change (`add-purpose-section`).
2. Open a pull request into the default branch (`main`).
3. Request a GitHub Copilot code review on that pull request.

The only change in this branch is this section — a deliberately small, reviewable diff so the Copilot review has something concrete to comment on.
